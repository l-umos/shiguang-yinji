# 时光印记 · AI 记忆管理应用（ShiGuang YinJi）

一款面向**个人生活记录**的 AI 记忆管理应用：像聊天一样记录生活，AI 帮你整理成结构化记忆，随时回顾、总结、分析。

> 基于 Capacitor 的混合应用（Kotlin 原生壳 + H5 前端），通过吐司APP 低代码平台**迭代 30 代**打磨成型。简历作品项目。

## ✨ 核心能力

- 🗣️ **自然语言记录**：像聊天一样记生活——"昨天晚上八点和张三吃饭，聊了找工作的事情，心情很好"，AI 自动理解并保存
- 🧠 **AI 结构化记忆（AI Memory）**：把用户信息抽象为**事件、人物、情绪、时间线**等实体，实现长期记忆管理
- 🔍 **回顾与总结**：随时问"我和张三上个月聊了什么"，AI 检索历史数据并给出总结与分析
- 🤖 **Agent 工具调用**：AI 不只是生成文字，还能**执行实际操作**——创建/修改/删除事件、创建/修改人物信息
- ✅ **可靠性校验**：针对真实开发中"AI 回复成功但数据库没改"的问题，增加**数据校验 + 执行结果验证**机制
- 👥 **人物档案管理**：人物分组、生日信息、关联事件查询
- 🎙️ **多模态输入**：支持文本、图片、语音转文字，探索多模态 AI 在个人知识管理中的应用

## 🚀 快速安装

1. 用手机浏览器打开 [Releases](https://github.com/l-umos/shiguang-yinji/releases) 下载 `shiguang-yinji.apk`
2. 在手机设置里允许「安装未知来源应用」
3. 点击安装，打开即可使用

> ⚠️ 小提示：不要用微信等聊天工具转发 APK——聊天工具容易损坏文件或触发安装拦截，直接从 GitHub 下载最稳妥。

## 🏗️ 我是怎么做出这个项目的

**从想法到 30 代迭代**：我没有一开始就写代码，而是用吐司APP 一步步沟通，每代加一个能力——先让它"听懂一句话并记下来"，再逐步长出人物档案、情绪记录、AI 查询总结、工具调用。30 代迭代的过程本身就是产品思维和快速验证能力的体现。

**AI Memory 怎么设计**：核心是实体抽象。用户输入的是自然语言，系统把它拆成**事件（时间+地点+内容）、人物、情绪、时间线**四类实体，结构化保存，之后才能被检索和总结。

**Agent 工具调用闭环**：AI 收到指令后先判断"要不要动手"，需要的话调用工具（创建/修改/删除事件、人物等）执行真实操作，再把结果回传、生成回复。开发中踩过一个典型坑——AI 回复"已保存"但数据其实没写入，所以加了**写前数据校验**和**写后执行结果验证**，让 Agent 的操作可靠可查。

**多模态输入**：文本之外支持图片、语音转文字（语音走腾讯 `audio_to_text` 服务），把不同形态的生活记录统一进记忆库。
